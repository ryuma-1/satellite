# タスク作成の手順

新しいタスクの作成を依頼されたら，次の手順に従ってください．

1. 依頼を受け，タイトル・見積り時間（estimatedHours）・締切（deadline）のうち，依頼文からすでに読み取れる項目を書き出してください．
2. `check_task_draft` を呼び，タイトル・見積り時間・締切がすべて揃っているか確認してください．
3. `missing` に項目が残っている間は，不足している項目ごとに `ask_user` で質問し，回答を反映してから再度 `check_task_draft` を呼んでください（`complete: true` になるまで手順2・3を繰り返す）．`ask_user` が `{ answered: false }` を返した場合（回答が得られなかった場合）は，質問を繰り返さず，そこで作業を止めてユーザーにその旨を伝えてください．
4. `list_tasks` で似た内容の既存タスクがないか確認してください．重複の可能性があれば，あとでユーザーへの提示に含めてください．
5. タスクが大きいと判断した場合は，サブタスクへの分割案を組み立ててください（分割の要否・内容はあなた自身の判断で決めてください．コード側には分割ロジックはありません）．分割した場合は，各サブタスクについて手順6以降を繰り返してください．
6. `find_free_slot` を，そのタスク（またはサブタスク）の締切を `deadline` に指定して呼んでください．返ってきた `date` を期日として保存してください．`slotStart` はその日の空き時間の開始を示す参考情報であり，ユーザーへの提示にのみ使い，保存はしないでください．`fits: false` が返った場合は，期間内に空きがないことを提示に含めてください．
7. `create_task` を呼んでください．タイトル・`due`（手順6で得た `date`）・`estimatedHours`（見積り時間，サブタスクに分割した場合は親タスクではなく各サブタスクに渡す）・重複や分割案の説明を渡してください．`create_task` の実行前には，内容を確認するプロンプトが必ず表示されるため，この手順内で確認呼び出しを別途行う必要はありません．確認が拒否された場合は，そのタスク（またはサブタスク）を作成しなかったことをユーザーに伝えて終了してください．
